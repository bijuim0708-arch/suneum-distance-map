주소 Excel을 좌표 Excel로 변환

선이음-오십보백보 직원용

이 화면은 주소를 좌표로 변환하고 결과 파일을 저장하는 업무만 수행합니다.

1. 원본 Excel 불러오기

투표소명과 주소 열이 있는 Excel 또는 CSV를 선택하세요. 이미 위도·경도가 있으면 그대로 유지합니다.

아직 원본 파일을 선택하지 않았습니다.

2. Kakao JavaScript 키

Kakao Developers의 JavaScript 키를 사용하세요. REST API 키가 아닙니다. 등록 도메인은 현재 직원용 페이지 주소를 추가해야 합니다.

키를 입력한 뒤 저장하세요.

3. 좌표 변환

원본 파일과 Kakao JavaScript 키를 준비하세요.
행구분투표소명주소위도경도상태

사용 순서

  1. 주소가 들어 있는 원본 Excel을 선택합니다.
  2. Kakao JavaScript 키를 입력하고 저장합니다.
  3. 변환이 끝나면 좌표 Excel을 저장합니다.
  4. 저장된 좌표 Excel을 현장용 데이터 제작에 사용합니다.
