# 선이음-거리맵 v0.1

투표소 주변 현장단속 거리 확인 도구입니다.

구·군위원회가 관리하는 사전투표소·선거일 투표소 Excel을 불러오면 투표소 위치를 지도에 표시하고, 선택한 투표소 기준 반경 50m와 100m를 확인할 수 있습니다.

본 프로그램은 거리 확인용 업무 보조도구입니다. 특정 행위의 공직선거법 위반 여부를 자동으로 판단하지 않습니다.

## 1. 실행방법

1. 모바일 현장 테스트는 `mobile-standalone.html`을 우선 사용합니다.
2. 정식 폴더형 배포는 `index.html`과 `css/`, `js/`, `data/` 폴더를 함께 웹서버 또는 정적 호스팅에 올립니다.
2. 스마트폰 Chrome 등 모바일 브라우저에서 접속합니다.
3. `투표소 Excel 불러오기`를 눌러 투표소 파일을 선택합니다.

권장 방식은 HTTPS 주소로 접속하는 것입니다. 스마트폰 위치 기능은 보통 HTTPS 환경에서 가장 안정적으로 작동합니다.

`index.html`만 따로 옮기면 CSS/JS 폴더를 찾지 못해 지도와 화면 스타일이 깨질 수 있습니다. 파일 하나로 보내야 할 때는 `mobile-standalone.html`을 사용하세요.

휴대폰 주소창이 `content://...` 또는 `file://...`로 시작하면 내 위치 기능이 제한될 수 있습니다. 이 경우 HTTPS 주소로 접속하거나 `위치 찍기` 버튼으로 지도 위의 현장 위치를 직접 지정하세요.

## 2. Excel 작성방법

첫 번째 시트의 첫 행을 제목 행으로 사용합니다.

기본 형식:

| 구분 | 투표소명 | 건물명 | 주소 | 위도 | 경도 | 비고 |
| --- | --- | --- | --- | --- | --- | --- |
| 사전투표소 | 테스트동 사전투표소 | 테스트동 행정복지센터 | 대구광역시 테스트구 테스트로 10 | 35.8853 | 128.6108 | 테스트 데이터 |
| 투표소 | 테스트동 제1투표소 | 테스트초등학교 체육관 | 대구광역시 테스트구 테스트로 20 | 35.8847 | 128.6122 | 테스트 데이터 |

## 3. 필수 Excel 열

필수 열:

- 구분
- 투표소명
- 주소
- 위도
- 경도

선택 열:

- 건물명
- 비고

`구분`에는 `사전투표소` 또는 `투표소`를 입력합니다.

## 4. 투표소 추가방법

Excel 마지막 행 아래에 새 투표소를 추가합니다.

위도·경도는 반드시 실제 위치를 확인해 입력합니다. 주소만 입력한 경우 v0.1은 임의 좌표를 만들지 않고 "좌표 확인 필요"로 표시합니다.

## 5. 투표소 수정방법

Excel에서 해당 행의 투표소명, 건물명, 주소, 위도, 경도, 비고를 수정한 뒤 다시 불러오면 됩니다.

프로그램 소스코드는 수정하지 않아도 됩니다.

## 6. 새 선거 때 데이터 교체방법

새 선거의 투표소 Excel만 준비해 다시 불러오면 됩니다.

예:

- 거리맵 프로그램 폴더
- `2026_지방선거_북구_투표소.xlsx`
- `2027_재보궐선거_북구_투표소.xlsx`

프로그램과 투표소 데이터는 분리되어 있습니다.

## 7. 지도 API 설정방법

v0.1은 Leaflet + OpenStreetMap을 사용하므로 별도 API Key가 필요 없습니다.

다만 OpenStreetMap 기본 타일 서버는 대규모·상시 서비스용 서버가 아닙니다. 기관 단위 정식 운영 전에는 이용 정책, 접속량, 대체 지도 제공 방식을 검토해야 합니다.

Kakao Maps, Naver Maps, VWorld로 바꾸는 경우에는 API Key와 도메인 제한 설정이 필요합니다. 키를 HTML에 직접 넣으면 외부에 노출될 수 있으므로 주의해야 합니다.

## 8. 스마트폰 사용방법

1. 모바일 브라우저에서 거리맵 주소를 엽니다.
2. Excel을 불러옵니다.
3. 상단 검색창에 동명, 투표소명, 건물명, 주소 일부를 입력합니다.
4. 투표소를 선택합니다.
5. 하단에서 `50m`, `100m`, `50+100m`를 누릅니다.
6. `내 위치`를 누르면 현재 위치와 선택 투표소의 직선거리를 확인할 수 있습니다.
7. GPS 권한이 안 되면 `위치 찍기`를 누른 뒤 지도에서 문제 장소를 직접 누릅니다.

## 9. 위치권한 허용방법

`내 위치` 버튼을 누르면 브라우저가 위치 권한을 요청합니다.

허용하면 현재 위치가 지도에 표시됩니다. GPS 정확도 값이 있으면 오차범위 원도 함께 표시됩니다.

정확도가 낮거나 50m/100m 경계 부근이면 현장 확인이 필요합니다.

## 10. 오류 발생 시 확인방법

대표 오류:

- `필수 열 없음`: Excel 제목 행에 필요한 열이 없습니다.
- `주소가 없습니다`: 주소 칸이 비어 있습니다.
- `위도 값이 없습니다`: 위도 칸이 비어 있습니다.
- `경도 값이 없습니다`: 경도 칸이 비어 있습니다.
- `위도 형식 오류`: 위도 값이 -90~90 범위를 벗어났거나 숫자가 아닙니다.
- `경도 형식 오류`: 경도 값이 -180~180 범위를 벗어났거나 숫자가 아닙니다.
- `중복 투표소`: 구분, 투표소명, 주소가 같은 행이 있습니다.

오류는 예를 들어 `3행 테스트동 제1투표소: 경도 값이 없습니다.`처럼 행 번호와 함께 표시됩니다.

## 11. 업무 참고용 안내문

본 프로그램의 거리 표시는 등록된 투표소 좌표 및 지도/GPS 정보를 기반으로 산출한 참고자료입니다.

지도상 거리와 실제 현장 측정값에는 차이가 있을 수 있으며, 특히 거리 제한 경계 부근에서는 현장 확인 및 관계 법령에 따른 별도 판단이 필요합니다.

본 프로그램은 특정 행위의 공직선거법 위반 여부를 자동으로 판단하지 않습니다.
